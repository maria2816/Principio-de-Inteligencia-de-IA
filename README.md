## 📊 2. Tabla Comparativa de Herramientas

| Criterio | Herramienta 1: Teachable Machine | Herramienta 2: Hugging Face (NVIDIA) |
| :--- | :--- | :--- |
| **¿Qué hace y a quién va dirigido?** | Clasificación interactiva de imágenes mediante cámara web. Dirigido a principiantes y estudiantes sin experiencia en código. | Transcripción, alineación de letras y separación de audio. Dirigido a entusiastas de la IA, músicos y creadores de contenido. |
| **Tipo de modelo que usa** | Utiliza **redes neuronales convolucionales (CNN)** de visión por computadora mediante aprendizaje por transferencia. | Utiliza un **modelo de lenguaje y reconocimiento de voz (ASR)** pre-entrenado de última generación por NVIDIA. |
| **Facilidad de uso y datos** | Alta facilidad (interfaz 100% no-code gráfica). Requiere que el usuario grabe sus propias muestras para entrenar. | Alta facilidad en su versión web interactiva. No requiere datos de entrenamiento; el modelo ya viene pre-entrenado de fábrica. |
| **Casos de uso potenciales** | Control de acceso básico, prototipos de aplicaciones de asistencia visual o juegos activados por gestos corporales. | Creación automática de subtítulos para videos, sistemas de karaoke automatizados o herramientas de transcripción de reuniones. |
| **Limitaciones y sesgos** | Muy dependiente de que las fotos iniciales tengan buena iluminación y fondos limpios para no confundirse. | Puede presentar fallas o sesgos si el audio tiene demasiado ruido de fondo o si el acento del hablante es muy cerrado. |

## 📝 3. Tool Comparison Summary (Requisito en Inglés)

Both platforms offer excellent entry points for exploring artificial intelligence through **no-code** interfaces. Teachable Machine allows users to easily implement **transfer learning** by training a custom classification system with minimal samples. On the other hand, Hugging Face provides immediate access to a vast repository where anyone can test a **pre-trained model** for complex tasks. During execution, the web application performs fast **inference** on new data without requiring heavy local hardware resources. Finally, while Teachable Machine focuses on quick prototyping from scratch, Hugging Face opens the possibility for advanced users to perform **fine-tuning** on specialized datasets later on.

---

## ⚖️ 4. Reflexión Ética

A nivel ético, es fundamental notar que Teachable Machine depende por completo de los datos suministrados en vivo por el usuario, lo que puede inducir a sesgos discriminatorios si no se balancean las clases con muestras diversas. Por su parte, la herramienta de Hugging Face de NVIDIA puede heredar sesgos lingüísticos según el idioma, jergas y los acentos incluidos originalmente por los desarrolladores en su entrenamiento masivo en internet, excluyendo potencialmente ciertas variantes culturales del habla.
